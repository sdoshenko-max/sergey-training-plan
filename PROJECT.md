# Проект: план тренировок Сергея

## Что это

Статический сайт с пятидневным планом на массу и фотографиями оборудования из зала Сергея. Обновлён по согласованному в беседе плану 21 ноября 2026 года.

- Сайт: https://sdoshenko-max.github.io/sergey-training-plan/
- Репозиторий: https://github.com/sdoshenko-max/sergey-training-plan
- GitHub Pages: ветка `main`, каталог `/`.
- Предыдущая локальная папка на Windows: `D:\Cloude CODE\training-plan-site`. При продолжении там сначала получить актуальные изменения из `main`.

## Актуальный план

- Период: 13 недель, с 23 ноября 2026 по 19 февраля 2027.
- Зал: понедельник–пятница в 12:00.
- Понедельник — грудь; вторник — спина; среда — плечи; четверг — руки; пятница — ноги.
- Футбол: понедельник и четверг в 19:00. Суббота и воскресенье — восстановление.
- 17 упражнений в неделю, по 3–4 упражнения на тренировку.
- Используется 9 фотографий, предоставленных пользователем. Один снимок оборудования может относиться к нескольким упражнениям.
- 6-я и 12-я недели облегчённые: количество рабочих подходов округляется вверх от половины обычного, не менее одного.

Новый запрос пользователя на пятидневный план с ногами заменяет прежнее ограничение «ноги не добавлять». Дополнительное кардио, питание, новые упражнения и произвольные рабочие веса не добавлять.

## Нагрузка и техника

- Указаны рабочие подходы; разминка выполняется отдельно.
- Обычно оставлять 2–3 качественных повтора в запасе; в облегчённые недели — 3–4.
- Если верхняя граница повторений выполнена во всех подходах с тем же запасом, можно добавить минимальный доступный вес.
- В пятницу после футбола оценить восстановление: при выраженной усталости сократить объём примерно вдвое и убрать румынскую тягу. Не тренироваться через острую или суставную боль.
- Каждое упражнение раскрывает фото, инвентарь, отдых и список подсказок: настройка, движение, дыхание, важные замечания.

## Интерфейс

- Светлый нейтральный дизайн, без маркетинговых блоков.
- Недели показываются последовательно; сверху есть переход к нужной неделе.
- Дни раскрываются по клику; одновременно открыт один день.
- Упражнения раскрываются внутри дня. При закрытии дня закрываются его упражнения.
- Фотографии показываются целиком, без обрезки тренажёров. По нажатию открывается отдельное фото.
- Мобильная версия без горизонтального скролла. Учитывается `prefers-reduced-motion`.
- Сайт не хранит рабочие веса, выполненные подходы или персональный журнал в localStorage.

## Файлы

- `index.html` — оболочка, расписание, правила нагрузки, навигация.
- `plan-data.js` — дата начала, 13 недель, 5 тренировок и 17 упражнений с фото и техникой.
- `app.js` — расчёт дат и облегчённых подходов, рендер и аккордеоны.
- `styles.css` — оформление, фотографии, адаптив.
- `assets/equipment/*.jpg` — оптимизированные фотографии без EXIF/GPS.
- `.nojekyll` — отключение Jekyll.
- `test-site.mjs` — локальные проверки; исключён из Git.

## Обновление

1. Получить актуальное состояние `main`.
2. Изменить данные или интерфейс.
3. Выполнить `node --check app.js`, `node --check plan-data.js`; проверить рендер, даты, пути фото и взаимодействия в браузере.
4. Опубликовать изменения в `main` обычным fast-forward либо обновлением ref с проверкой ожидаемого SHA. Не использовать force push.
5. Проверить успешное обновление GitHub Pages и публичную страницу.

Cloudflare Pages и Sites не используются для публикации проекта. Исходная летняя версия плана сохранена в истории Git.
